# 証言

寄せていただいた話を、一件ずつファイルにして置く場所です。

- ファイル名は `YYYYMMDD_短い見出し.md` とします
- 書式は [_template.md](_template.md) にならいます
- **本人の確認が取れていないものは公開しません**
- **氏名は公開しません。**語ってくださった方の情報は「関川村在住の方」のように**市町村の単位まで**にとどめます（集落名・年代・性別・役職も書きません）
- 連絡先など個人を特定できる情報は書きません（Git 管理外の `private/` に置きます）
