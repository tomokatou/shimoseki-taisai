## 5分で分かる、いまの状況

**祭りの由来を書いた資料は、いまも見つかっていません。** 創始年も、「ヤレカガオギレ」の語源も、活字になっていません。

そのかわり、**別の道から事実が出てきました。**

- 大輪は **宝暦4年（1754年）製作と云われる**。昭和42年の羽越大水害で組み立て中に流され、残った一部に修理が加えられた（『新潟県の山車』新潟県教育委員会 1987）
- **平成29年（2017年）、大輪が修繕されている。**事業名は「**下関大祭大輪の修繕**」、**250万円**、宝くじ助成10分の10（村議会の会議録と、国の助成の交付一覧の両方に記録）
- **村の広報紙に、この祭りは出てこない。**本誌39号＋お知らせ版70号を全文検索して0件。集落の行事は村の広報の対象になっていない
- **知らないだけで、続いているものがある。**高田集落の大輪、高田まつり、大蔵神社の夏越のお祓い、大石の獅子舞、南中の三匹獅子・剣の舞——**どれも検索しても何も出てきません**
- 大輪は**一基**、車輪は**二つ**で木のまま。あおりは「◯◯様より花があがりました」の声で始まる（2026年の担ぎ手の証言）

→ くわしくは [**サイトの「村の記録から」**](https://tomokatou.github.io/shimoseki-taisai/#kiroku) と [docs/known.md](docs/known.md)

**このアーカイブの仕事は、失われかけたものを記録することだけではありません。
すでにあるのに見えていないものを、見えるようにすることでもあります。**

## なぜ作ったか

下関大祭について、いまインターネットで調べられることはごくわずかです。
開催日と「大輪と山車が練り歩く」という数行の紹介があるだけでした。

調べていくうちに、県の調査報告書や村史にたどり着き、分かったこともあります。
それでも、まだ答えの出ていない問いが残っています。

- **なぜ「ヤレカガオギレ」と言いながら戸を叩くのか**
- **大輪は何基あり、どの町内が受け持ってきたのか**
- **昭和42年の水害で流されたとき、どの部分が残ったのか**

担ってきた方々の記憶にはあるはずの話が、どこにも書き留められていません。
それを少しずつ集めて、来年、再来年と読める形で残していくための場所です。

## 情報をお寄せいただけませんか

**どんな断片でも構いません。**「子どもの頃こうだった」「うちの町内ではこう呼んでいた」という一言が、あとから他の証言とつながって意味を持ちます。年代が曖昧でも、うろ覚えでも大丈夫です。

お寄せいただく方法は3つあります。

| 方法 | 向いている場合 |
|---|---|
| [Issue](../../issues/new/choose) | 具体的な思い出・資料の提供・記載の誤りの指摘 |
| [Discussions](../../discussions) | 雑談として話したいこと、確証はないけれど覚えていること |
| 直接 | GitHubをお使いにならない方には、運営者が聞き取りにうかがいます |

GitHubのアカウントをお持ちでない方が大半だと思います。**ご家族や知り合いを通じて、口頭でお聞かせいただく形でも構いません。**こちらで書き起こして掲載します。

## 掲載のルール

- 掲載前に、**語ってくださった方に内容を確認**していただきます
- **お名前は公開しません。**語ってくださった方の情報は「関川村在住の方」のように**市町村の単位まで**にとどめます（集落名・年代・性別・役職も書きません）
- 連絡先・住所はこのリポジトリに一切保存しません
- 掲載をやめてほしいというご連絡があれば、**理由を問わず取り下げます**
- 確証のない話は「未確認」と明記して載せます。**間違いを恐れて黙っているより、印をつけて残すほうが価値がある**と考えるためです

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。
