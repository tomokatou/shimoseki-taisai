# 下関大祭アーカイブ

新潟県岩船郡関川村・下関（しもせき）地区に伝わる **下関大祭** の記録を集めて公開するプロジェクトです。

> **これは非公式のアーカイブです。**
> 祭りの主催者・氏子組織・関川村役場とは関係のない有志（Hollyhocks／加藤）が運営しています。
> 公式の情報については関川村役場・関川村観光協会にお問い合わせください。

サイト: https://tomokatou.github.io/shimoseki-taisai/

---

## なぜ作ったか

下関大祭について、いまインターネットで調べられることはごくわずかです。
開催日と「台輪と山車が練り歩く」という数行の紹介があるだけで、

- **いつ始まったのか**
- **なぜ「ヤレカガオギレ」と言いながら戸を叩くのか**
- **台輪は何基あり、どの町内が受け持ってきたのか**

こうしたことを書いた資料が、ほとんど見あたりません。

祭りを担ってきた方々の記憶の中にはあるはずの話が、どこにも書き留められていない。
それを少しずつ集めて、来年、再来年と読める形で残していくための場所です。

## 情報を寄せていただけませんか

**どんな断片でも構いません。**「子どもの頃こうだった」「うちの町内ではこう呼んでいた」という一言が、あとから他の証言とつながって意味を持ちます。年代が曖昧でも、うろ覚えでも大丈夫です。

寄せ方は3つあります。

| 方法 | 向いている場合 |
|---|---|
| [Issue](../../issues/new/choose) | 具体的な思い出・資料の提供・記載の誤りの指摘 |
| [Discussions](../../discussions) | 雑談として話したいこと、確証はないけれど覚えていること |
| 直接 | GitHubを使わない方から、運営者が聞き取りでうかがいます |

GitHubのアカウントをお持ちでない方が大半だと思います。**ご家族や知り合いを通じて、口頭でお聞かせいただく形でも構いません。**こちらで書き起こして掲載します。

## 掲載のルール

- 掲載前に、**語ってくださった方に内容を確認**していただきます
- 氏名の公開は**ご本人が望まれる場合のみ**。既定では「下関在住・80代・男性」のような形にします
- 連絡先・住所はこのリポジトリに一切保存しません
- 掲載をやめてほしいというご連絡があれば、**理由を問わず取り下げます**
- 確証のない話は「未確認」と明記して載せます。**間違いを恐れて黙っているより、印をつけて残すほうが価値がある**と考えるためです

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。
